# Bootcamp Project Tracker

A simple web application to track and manage projects, allowing users to add, edit, delete, and mark projects as completed or ongoing.

![Project Screenshot](127.0.0.1_5500_frontend_index.html(iPhone%2016%20-%201).png)

## **Features**
1. **Add New Projects**  
   - Enter project name, description, and status (ongoing/completed).  
   - Submit to save the project.  

2. **Edit Existing Projects**  
   - Modify project name or description.  
   - Save changes to update the project.  

3. **Delete Projects**  
   - Remove projects permanently.  

4. **Toggle Project Status**  
   - Switch between "ongoing" and "completed" states.  

---

## **Technologies Used**
- **Frontend:**  
  - HTML, CSS, JavaScript  
  - Fetch API for server communication  

- **Backend:**  
  - Node.js (Express.js)  
  - In-memory data storage (for simplicity)
